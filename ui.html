TT-Localize

Select frames, upload your copy sheet, and generate a localised copy of each frame per language.
Text layers are matched by layer name first, then by their current text.
Re-running replaces frames with the same name inside an existing language section.
Keeping bold / coloured words
Words that stay the same (prices, numbers, brand names) keep their style automatically. For translated words, wrap them in tags in your sheet:
<1>…</1>, <2>…</2> = 1st, 2nd styled part of the original text
<b> bold · <i> italic · <u> underlined
e.g. Jusqu'à <1>-50 %</1> cette semaine
Nothing selected
